## Cara Menjalankan Notebook

### Opsi 1 - Google Colab

1. Buka notebook yang diinginkan pada GitHub.
2. Salin URL notebook.
3. Buka Google Colab.
4. Pilih **File → Open Notebook → GitHub**.
5. Tempel URL notebook dan jalankan setiap sel.

### Opsi 2 - Menjalankan Secara Lokal

Clone repository:

```bash
git clone https://github.com/rakaanggie/data-science-2026.git
cd data-science-2026
```

Install dependency:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

Jalankan Jupyter Notebook:

```bash
jupyter notebook
```

Kemudian buka notebook yang ingin dijalankan.
